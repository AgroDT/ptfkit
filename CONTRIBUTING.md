# Contributing to ptfkit

Use [GitHub issues](https://github.com/AgroDT/ptfkit/issues) to report an
implementation error, request a PTF, or discuss a change whose scope is not yet
clear.

Pull requests are welcome for specification corrections, new PTFs, target and
generator changes, tests, and documentation. Before opening one:

1. Read the [development guide](https://agrodt.github.io/ptfkit/contributing/development/).
2. Keep the change focused and explain its scientific or technical basis.
3. Regenerate committed outputs when a specification or generator changes.
4. Run the checks relevant to every affected target.

New and corrected equations must remain traceable to their source publication.
Do not add source PDFs or local source paths to the repository.
