# Выводы ptfkit v1.0

Для каждой PTF использованы все экспериментальные точки ОГХ, которые она способна предсказать. Модели сравниваются по ошибке и покрытию; объёмная и массовая влажность анализируются отдельно.

База: 1701 экспериментальная точка, 142 образца, 19 источников. Объёмная влажность: 1069 точек; массовая: 632. Подогнанные и интерполированные значения не считаются независимыми измерениями.

## Объёмная ОГХ

Минимальная ошибка: `calc_ptf_cosby1984_univariate`: SB RMSE 0.022732; обычная RMSE 0.022609; точки 56/1069 (5.2%); образцы 6/77 (7.8%)

Лучшая индивидуальная модель при покрытии ≥25%: `calc_ptf_varallyai1982_chernozem_b`: SB RMSE 0.045390; обычная RMSE 0.043883; точки 608/1069 (56.9%); образцы 30/77 (39.0%)

Лучшая индивидуальная модель при покрытии ≥50%: `calc_ptf_varallyai1982_chernozem_b`: SB RMSE 0.045390; обычная RMSE 0.043883; точки 608/1069 (56.9%); образцы 30/77 (39.0%)

Лучшая индивидуальная модель при покрытии ≥75%: Нет модели с таким покрытием

Компромисс ошибки и покрытия (эвристический выбор на границе Парето): `calc_ptf_varallyai1982_chernozem_b`: SB RMSE 0.045390; обычная RMSE 0.043883; точки 608/1069 (56.9%); образцы 30/77 (39.0%)

Лучший ансамбль по проверке с исключением источника: `ensemble:median`: SB RMSE 0.055576; обычная RMSE 0.051167; точки 608/1069 (56.9%); образцы 30/77 (39.0%)

Ошибки получены на различных подмножествах; малое покрытие ограничивает интерпретацию минимальной RMSE. Ансамбли выбирают участников только по обучающим источникам.

Ансамбль улучшает ошибку при не меньшем покрытии относительно индивидуальной модели при пороге 50%: нет. Сравнение ошибок на общих точках: 0.055576 против 0.045390.
