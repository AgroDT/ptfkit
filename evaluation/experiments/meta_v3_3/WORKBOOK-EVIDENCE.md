# ptfkit workbook evidence audit

Validated on 2026-10-26: 1057 evaluation tests passed. Component lint, formatting
and type checks passed using installed Ruff 0.16.5 and ty 0.0.78; the experiment
module passed separate checks. Three isolated mutation probes were rejected:
ignoring sample ID, accepting an unrelated quantity as Ksat, and using an
incorrect centimetre-to-metre scale. Production files were not mutated.

Independent runs in `local/meta-workbook-evidence-reviewed` and
`local/meta-workbook-evidence-reviewed-replay` produced byte-identical inventories
for all eight artifacts, including the inventory itself. Inventory SHA256:
`6e05929f648468f63bbb46c2636f8b088985256794a5aa1e6a1a8b2e8066916d`.
Strict and exploratory prediction files also match the frozen 64-function campaign
byte for byte. The [reproduction instructions](README.md#ksat-and-predictor-evidence-review)
describe the command, frozen inputs and primary-document downloads.

The predictor review discarded 313 pH lexical hits in publication/soil/site text,
retaining five actual candidate headers. The machine-readable checkpoint preserves
the rejected addresses separately; none authorize measurement bindings.

Confirmed executable coverage: **64 -> 64 / 216**.

All three Ksat blocks were reviewed separately. No Ksat target or new predictor was released. A source-level method description does not establish the origin of an individual workbook value. No compatible Ksat pool exists yet; no Ksat error metric or pooled scientific conclusion is reported.

Strict predictions are recomputed and byte-identical to the frozen campaign. The full catalog was reevaluated at the final policy stage in both registered PSD scenarios. Existing approximate assumptions remain approximate; this audit does not upgrade their evidence.

## Corrections to the historical deep-unlock snapshot

AF/AG contain plastic/liquid-limit candidates, retracting the historical blanket absence classification for 17 functions. AC is heat of wetting. Literal AB41 is cm/smin, not confirmed cm/min. Historical artifacts remain frozen.
