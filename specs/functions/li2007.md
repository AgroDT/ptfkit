# Li et al. (2007)

## `calc_ptf_li2007`

### Constants

| name | value | units | description |
| --- | --- | --- | --- |
| CM_PER_DAY_TO_M_PER_SEC | 0.00000011574074074074075 | (m/s)/(cm/day) | Convert cm/day to m/s. |

### Formula

```text
theta_s = exp(-1.531 + 0.212 * ln(sand) + 0.006 * silt - 0.051 * soil_organic_matter - 0.566 * ln(bulk_density))
a_vg = exp(-67.408 - 0.040 * silt - 0.670 * ln(silt) - 2.189 * soil_organic_matter + 1.410 * ln(soil_organic_matter) + 78.400 * bulk_density - 121.331 * ln(bulk_density))
n_vg = 1.488 + 0.002 * ln(silt) + 0.013 * clay - 0.248 * ln(clay) + 0.048 * ln(soil_organic_matter) + 0.451 * ln(bulk_density)
k_sat_cm_per_day = exp(13.262 - 1.914 * ln(sand) - 0.974 * ln(silt) - 0.058 * clay - 1.709 * ln(soil_organic_matter) + 2.885 * soil_organic_matter - 8.026 * ln(bulk_density))
k_sat = k_sat_cm_per_day * CM_PER_DAY_TO_M_PER_SEC
```

Use `f64`, do not round, propagate NaN, and retain NumPy-compatible logarithm-domain behaviour.
