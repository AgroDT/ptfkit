# ptfkit Python bindings

Python bindings for `ptfkit`, a library of pedotransfer functions for estimating
soil hydraulic properties.

## Installation

```shell
pip install ptfkit
```

## Documentation

The [project README](https://github.com/AgroDT/ptfkit/) contains project-wide
documentation, including source builds, contributing guidance, and citation
information. The API documentation is available at
[https://agrodt.github.io/ptfkit/](https://agrodt.github.io/ptfkit/).
